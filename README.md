# reynovationTed

מאגר העבודה של ההרצאה (TED-style) והסרטונים הנגזרים ממנה.

## מבנה

| תיקייה / קובץ | מה נכנס לשם |
|---|---|
| `inbox/raw-notes.md` | כל נקודה, מחשבה, פרספקטיבה או סיפור – כמו שהם, בלי סינון. נקודת הכניסה לכל חומר חדש. |
| `core.md` | הליבה: הרעיון המרכזי במשפט אחד, קהל היעד, המסר, מה הקהל לוקח הביתה. |
| `talk/outline.md` | מבנה ההרצאה – פתיח, חלקים, מעברים, סיום. |
| `talk/opening.md` | עבודה מפורטת על הפתיח: ביטים, טיוטה, הנפשת התמונה. |
| `visuals/` | הדמיות חיות (HTML): `intro-options.html` (אפשרויות הפתיח), `prompter.html` (טלפרומפטר: פתיח ואז התסריט נגלל). המנוע המשותף ב-`intro-engine.js`. |
| `talk/script.md` | טקסט ההרצאה המלא (נכתב אחרי שהמבנה מתייצב). |
| `videos/backlog.md` | רעיונות לסרטונים קצרים שנגזרים מהתוכן, עם סטטוס. |
| `sources/references.md` | מקורות, נתונים, ציטוטים ומחקרים לגיבוי טענות. |

## תהליך

1. **איסוף** – חומר גולמי נכנס ל-`inbox/`.
2. **זיקוק** – מזהים את הרעיון המרכזי ומעדכנים את `core.md`.
3. **מבנה** – בונים את `talk/outline.md` סביב הרעיון המרכזי.
4. **כתיבה** – תסריט מלא ב-`talk/script.md`.
5. **גזירה** – כל חלק בהרצאה נבחן כסרטון קצר ב-`videos/backlog.md`.
