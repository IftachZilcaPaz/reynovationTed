## חלק 1: לפני
**משך משוער:** כ-3.4 דק' (כ-444 מילים)

[עולה לבמה. המסך שחור.]

שבעה באוקטובר. / שדרות. / אני בתוך הממ"ד.

אבל אני רוצה להתחיל הרבה לפני.

[מחייך] / אז קודם כל, / נעים מאוד, / אני יפתח.
[מסך: ‹תמונת ילדות, אתה ואמא›]
גדלתי עם אמא חד-הורית / מגיל מאוד צעיר. / אמא שעבדה בכמה עבודות במקביל / כדי שיהיה.
ואבא שלי? / הוא לא ממש היה שם. / עד גיל מאוד מאוחר.

אז בהרבה מקומות, / הרגשתי שגידלתי את עצמי.
מגיל קטן הייתי עצמאי מאוד, / וזה עשה ממני ילד שרוב הזמן הרגיש שהוא יודע מה הוא עושה. / ילד מאוד חדור מטרה.
רוב הזמן ידעתי מאוד מה אני רוצה לעשות, / ואף אחד לא הצליח להסיט אותי. / לא ימינה, / ולא שמאלה.

בנוסף לזה, / אני חושב שבעיקר בתחילת התיכון / הרגשתי שאני שונה. / הרגשתי עוף מוזר.

ובדרך כלל, / זה גם אומר ללכת הפוך מהנורמה.
אז מה זה אומר, / אתם שואלים?
למשל, / בגיל מאוחר יותר, / כולם הלכו ללמוד תואר? / אני החלטתי ללכת בדיוק במסלול ההפוך, / עד הסוף.
אנשים עושים קעקוע של דקל / בשריר האחורי של הרגל, / נכון?
אז אני / עשיתי אותו מקדימה. //
[מסך: ‹תמונת הקעקוע›]
[מחייך] / כן, / אני יודע.

[פונה לקהל]
רגע, / אני רוצה לשאול אתכם משהו.
מי כאן מרגיש ככה? / מי תמיד הלך בדרך קצת אחרת מכולם?
על מי תמיד חשבו שהוא עוף מוזר, / ולא הבינו למה הוא עושה דברים ככה / ולא אחרת?
[מחכה לידיים. מסתכל על האולם.]
תזכרו את הידיים האלה, / עוד נחזור אליהן.

[מסך: ‹תמונה שלכם מטיול, או מפת עולם›]
ואצל העוף המוזר הזה, / מאז ומתמיד, / היה רצון אחד: / לעשות דברים אחרת.
כשהייתי צעיר יותר / זאת הייתה המחשבה לעשות אולי עגלות בחול, / וכשגדלתי / התחיל לבעור בי מאוד רילוקיישן. / לאנשהו. / אפילו לתקופה.
ואז גיליתי שהאישה שבחרתי לחיים שלי / חולקת איתי בדיוק את אותו הרצון.

שנים דיברנו על זה עם כולם: / לצאת. / לטייל בעולם. / לעשות רילוקיישן. / משהו.

ובכל זאת, / בכל פעם הזמן עבר והמשיך. / ובכל פעם, / בנקודה מסוימת, / כשעצרנו רגע ואמרנו "טוב, / מה עכשיו?", / הבנו שנשארנו בדיוק באותו המקום.
לא מוצאים עבודה מרחוק. / לא משנה לאן שלחתי קורות חיים, / מה חשבתי שאני מחפש. / לא משנה כמה.
ותמיד חזרו המנטרה, / המחשבה, / ההרגל: / לא מוצאים. / לא קיים. / אין כאלה.
איך כולם מוצאים, / ואנחנו לא?

ובתוך המשפחה והחברים? / תמיד, / כשרק התחלנו לדבר על זה סביב השולחן, / כמעט כולם אמרו לנו:
"למה אתם צריכים את זה? / מה זה ייתן לכם? / למה להתעקש? / למה להיות שונים?"
והיו גם כאלה שלא אמרו כלום. / רק נתנו את התחושה: / "בסדר, תנסו. / לא תצליחו."

ותמיד חוזרת המנטרה, / שוב ושוב:
אי אפשר. / לא עכשיו. / מחר. / עוד שנה. //

וככה עברו השנים.

[מסך: ‹סרטון מהטלפון: רציף, רכבת, בוקר מוקדם›]
ובינתיים המשכתי, / כמו כולם, / לעלות על רכבות. / גם זאת שעל הפסים, / וגם המטאפורית.
קם בבוקר לפני שמישהו בכלל חושב להתעורר. / מתארגן מהר-מהר.
פקק בדרך לרכבת. / הרכבת מתעכבת.
ומגיע לעבודה כשחצי יום כבר נשרף.
ואז יושבים מול המקלדת בלי לזוז. / שחס וחלילה לא תהיה לנו הפסקה.
נגמר היום, / חוזרים הביתה, / ולפעמים מפספסים את הרכבת / ומחכים שעה לבאה. / במקרה הטוב.
וכולם מגיעים לעבודה חולים. / כי אסור לפספס יום.

זאת הייתה הרכבת שלי. //
שכל אחד יחשוב / איפה הרכבת שלו. / לא רק זאת שעל הפסים, / אלא הרכבת של החיים.

## חלק 2: נקודת המפנה
**משך משוער:** כ-3.6 דק' (כ-462 מילים)

יום אחד, / בעבודה שהייתי בה כבר שנים, / קולגה זרק לי משפט. / בזלזול.
משהו כמו: / "אתה? / אתה לא מסוגל."
"אולי מי שהחליט לא לתת לך, / יש לו סיבה טובה לחשוב את זה."
ועוד כל מיני הערות של הקטנה. / של "אתה לא תוכל להתקדם. / להיות במקום אחר. / להתפתח".
ובאותה תקופה, / האמת, / באמת הרגשתי תקוע. / בנוח שלי.
וזאת הייתה עוד סטירה. / אבל הפעם, / ישר למוח. //
היא איפסה אותי.

כי אני מספיק מכיר את עצמי: / אין משהו שאני רוצה, / ולא יכול. / תמיד היה ככה.

[פונה לקהל]
אני בטוח שלרבים מאיתנו היה מישהו כזה בחיים. / שלא האמין בנו מספיק, / ונתן לנו סטירה כל כך מצלצלת, / שלא יכולנו להמשיך לשבת ולשתוק.
אבל לזה / עוד אחזור בהמשך.

ואז, / פאסט פורוורד: / כמובן שהצלחתי. / למדתי, / ועשיתי שיפט. ‹ממה, ולמה›
הגעתי ליעדים שהצבתי לעצמי. / עבדתי בחברות כמו פלייטיקה / וצ'ק פוינט.
[מסך: ‹תמונה מהמשרד, או הלוגואים›]
אבל מה שיפה, / הוא שבאותה מידה, / גם האופי שלי השתנה / במאה שמונים מעלות.
גיליתי בעצמי עוד הרבה יכולות / שלא הכרתי מספיק רוב החיים שלי.

ושוב, / כמו רוטינה, / עלו השיחות: / "טוב, / נמשיך במקומות העבודה האלה. / נתקדם. / נתפתח. / ונעוף מפה."
ושוב, / חוזר חלילה.

[מסך: ‹תמונה מהממ"ד, 7 באוקטובר›]
ואם נתקדם עוד קצת בחיים, / אז לימים, / הגיע השביעי באוקטובר. //
ישבתי נעול בממ"ד. / קרה כל מה שקרה.
ולאט-לאט, / בפעם הראשונה, / זה היכה בי באמת.
ההבנה הזאת ש... //
לא הייתי נעול בממ"ד רק באותו היום. / מטאפורית, / אני כבר שנים נמצא בסוג של ממ"ד סגור. //
ממ"ד שנקרא "אי אפשר". / "לא עכשיו". / "מחר". / "עוד שנה".

ופתאום, / אחרי חוויה כל כך מטלטלת, / בדמות מחבלים בבית שלנו, / שוב משהו התחיל לזוז. / אבל הפעם, / קצת יותר חזק. / למרות שעדיין לא ידעתי לאן.
וכל יום שעבר, / ראיתי ושמעתי על עוד ועוד אנשים שעזבו הכול. / על אנשים ששינו משהו. / על אנשים שפשוט התחילו לזוז.
ואני? / אם שאלתם, / עדיין הייתי אותו בחור / שרץ לרכבות.

[מסך: ‹תמונה ראשונה עם הבן›]
ואם נתקדם עוד קצת, / אז גם נולד לי הבן הבכור שלי.
וזה, / בפני עצמו, / נותן לך סטירה מטורפת. / ומניע אותך, / בין אם תרצה ובין אם לא.
בסוף, / יש לך אחריות מטורפת!
ואז אתה יושב לילה אחד, / הוא נרדם עליך, / והכול מתחיל להציף אותך. / והמחשבות מתחילות לנדוד:
מה אני רוצה לעשות? / איפה אני רואה את עצמי? //
וההחלטה הראשונה שלקחתי, / והחלטתי שאני עומד בה / לא משנה מה יקרה, / היא לצאת בשעה נורמלית הביתה. / כדי להספיק לראות את הילד שלי.
משהו שבעיניי היה הכי בסיסי בעולם:
לצאת מהעבודה בחמש. / להגיע הביתה בשש וחצי, / במקרה הטוב.
לעזור לאשתי, / ולהיות עם הבן שלי.
כדי שהוא יכיר את אבא שלו. / ולא יהיה הילד שאבא שלו יוצא כשהוא ישן, / וחוזר כשהוא ישן. //

אני יודע איך זה מרגיש, / כשאבא לא שם. //

ואז, / כמובן... / [מחייך] / ניחשתם נכון. / מתחילות ההערות:
"חצי יום עבודה, אה?"
"אתה יוצא מוקדם מדי, אה? / זה בעייתי, / זה בעייתי."

כל הערה כזאת, / פתאום אתה מרגיש אותה מהדהדת כפליים.
וזה מרגיש כמו סטירה. / ועוד סטירה. / ועוד אחת.
אבל כל סטירה כזאת עשתה משהו מוזר:
היא לא הזיזה אותי אחורה. / היא דייקה אותי. //
היא ממש גרמה לי להיות עוד יותר חד, / ומפוקס, / לגבי מה שאני באמת רוצה.

## חלק 3: הקוד שירשנו
**משך משוער:** כ-4.1 דק' (כ-537 מילים)

אז מי כתב את הקוד הזה?

הרבה ממנו, / כתבו בשבילנו. / כשהיינו ילדים.
מדברים שראינו. / מדברים ששמענו. / מדברים שהחדירו בנו. / בלי שאף אחד התכוון.

ילד לא לומד לפחד מכלבים / לבדו.
הוא לומד את זה מהפנים של אמא שלו, / כשהכלב עובר.
וזה לא רק משפט יפה: / חוקרים הראו את זה במעבדה.
ילדים שראו הורה מפחד ממשהו, / התחילו לפחד מאותו הדבר בעצמם. / גם כשלא קרה להם כלום.

ורוב הפחדים שלנו / הם בדיוק זה: / קוד שירשנו.
ההורים שלנו פחדו. / הם לא זזו מאזור הנוחות. / לא פגשו חברים. / לא יצאו. / לא עשו.
והם לא אשמים. / גם הם קיבלו את הקוד הזה / ממישהו.

חוקרת בשם רחל יהודה / בדקה ילדים של ניצולי שואה, / ומצאה סימנים לטראומה של ההורים / גם בגוף של הילדים.
זה מחקר קטן, / והמדע עוד לא סגור עליו.
אבל כל מי שגדל כאן יודע, / שיש דברים שעוברים בבית / בלי שאף אחד אומר אותם.

וזה לא רק פחדים. / זה גם אמונות.
משפטים שקיבלנו מהסביבה. / מההורים. / לא משנה מאיפה. / ואימצנו אותם / כאילו הם שלנו.
"אני לא טוב עם אנשים."
"אני לא טוב בזה." / "אני לא טוב בההוא."
ומרגע שאימצנו, / אנחנו כל היום מחפשים לזה הוכחות. / ומוצאים. / בכל רגע.

ופה יש הבדל, / שלקח לי שנים להבין: / ההבדל בין אמונה, / לבין ידיעה.
[מסך: אמונה ≠ ידיעה]
אמונה, / זה משהו שמישהו אמר לי. / זה נשמע הגיוני. / אז אימצתי, / בלי לבדוק.
ידיעה, / זה לקחת את אותה אמונה, / ולבדוק אותה. / לצבור ידע. / להתנסות על עצמי. / ולהבין באמת / איך זה מרגיש.
"אין משרות כאלה." / זאת הייתה אמונה.
ועוד מעט, / אספר לכם מה קרה כשבדקתי.

ולפני כמעט שישים שנה, / שני חוקרים, / סליגמן ומאייר, / גילו משהו שהם קראו לו "חוסר אונים נלמד".
בעלי חיים שלמדו שמה שהם עושים לא משנה כלום, / הפסיקו לנסות. / גם כשכבר יכלו פשוט לצאת. //
חמישים שנה אחר כך, / הם חזרו לאותו מחקר, / והפכו את המסקנה:
חוסר האונים, / בכלל לא נלמד. / הוא ברירת המחדל של המוח.
מה שצריך ללמוד, / זה שיש לנו שליטה. //

"אי אפשר", / הוא לא תקלה. / הוא הגדרות היצרן.
ולכתוב מעליו, / זה בדיוק לתכנת את המוח.

אבל אנחנו רוצים, / ואנחנו צריכים, / להיות אחרים.

וזה מתחיל בזה, / שמוכנים להיות העוף המוזר.
כל מי שחורג מהנורמה, / נחשב קיצוני. / מוזר.
בלי תואר? / מוזר. / דקל מקדימה של הרגל? / מוזר.

ולמה כל כך קשה להיות שונים? / כי אנחנו מתוכנתים להתיישר.

בדרום אפריקה, / חוקרים לימדו קבוצות של קופים, / שתירס בצבע אחד טעים, / ובצבע השני מר.
[מסך: תירס ורוד, תירס כחול]
אחר כך הם הפסיקו להוסיף את החומר המר, / ושני הצבעים היו טעימים בדיוק אותו דבר.
והקופים? / המשיכו לאכול רק את הצבע "הנכון".
הגורים שנולדו, / אכלו מה שאכלו האמהות.
וכשעשרה זכרים עברו לקבוצה שאכלה את הצבע ההפוך, / תשעה מהם התחילו מיד / לאכול את מה שכולם אכלו.
והאחד שלא? / זכר האלפא. / זה שלא היה צריך את האישור של אף אחד.

ואצלנו? / זה לא שונה.
בשנות החמישים, / חוקר בשם סולומון אש / הושיב סטודנט בחדר עם עוד כמה אנשים, / ושאל שאלה פשוטה: / איזה קו הכי ארוך?
[מסך: שלושה קווים, אחד ארוך בבירור]
לבד, / כמעט אף אחד לא טעה.
אבל כל השאר בחדר היו שתולים. / והם ענו, / בכוונה, / תשובה לא נכונה.
ושלושה מכל ארבעה סטודנטים, / לפחות פעם אחת, / ויתרו על מה שהעיניים שלהם ראו. / והלכו עם הקבוצה. //

אבל הנה החלק שאני הכי אוהב.
כשאש הכניס לחדר / רק אדם אחד, / שענה אחרת מכולם, / ההתיישרות כמעט נעלמה. / משליש מהתשובות, / לחמישה אחוזים. //
אדם אחד. / עוף מוזר אחד.

[פונה לקהל]
זוכרים את הידיים שהרמתם קודם? / העוף המוזר?
זה לא באג. / זה פיצ'ר.
וכשאתם מעיזים להיות שונים, / אתם לא משחררים רק את עצמכם. / אתם משחררים את כל מי שיושב לידכם.

## חלק 4: לתכנת את המוח
**משך משוער:** כ-8.1 דק' (כ-1055 מילים)

[עצירה. צעד קדימה.]

אני רוצה לספר לכם עוד משהו עליי: / אני מתכנת. / במקצוע.

וזה תמיד יהיה מתוך הראייה שלהם. / כי רוב האנשים / חיים לפי שטנץ. / וזה בסדר. / לא כולם צריכים להיות העוף המוזר.

אבל מי שכן, / צריך ללמוד לשבת מולם.
מול מי שחושב הפוך ממנו. / לגמרי.
כי כברירת מחדל, / אנחנו נמשכים למקומות שנותנים לנו אישור. / לאנשים שמסכימים איתנו.
וזה בדיוק הקוד הישן.
הקוד החדש, / הוא לשבת מולו. / להקשיב לכל מה שהוא אומר. / באמת להבין.
ואז, / עדיין, / להחליט עם עצמי: / זה לא מתאים לי. / אני לא אותו הדבר. / אני יודע מה אני רוצה.

ועכשיו, / שאלה אחרת.
מי כאן מוכן למות בשביל הילדים שלו? / או בשביל מי שהוא הכי אוהב?
[ידיים] / כמעט כולם. / כמובן.

ועכשיו, / שאלה יותר קשה.
מי כאן מוכן לחיות בשבילם? //
לשנות הרגל. / לרדת במשקל. / לצאת מהעבודה בחמש. / לרדת מהרכבת.
למות בשביל מישהו, / זה רגע אחד.
לחיות בשבילו, / זה לתכנת את עצמך מחדש. / כל יום.

ואני לא אומר לעשות הכול.
רנדי צוקרברג אמרה את זה הכי פשוט: / עבודה. / שינה. / משפחה. / חברים. / כושר.
כל יום, / תבחרו שלושה.
שלושה מתוך חמישה. / לא חמישה.
ולבחור, / זה כבר לכתוב קוד.

אז אני שואל אתכם:
מה הממ"ד שלכם? //
איזה קוד רץ אצלכם, / שלא אתם כתבתם?

[מסך: דלת של ממ"ד, נפתחת]
[עצירה. תודה.]
